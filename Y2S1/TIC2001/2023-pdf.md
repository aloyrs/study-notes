**Question 3: Answer: c. O(N)**
For a complete binary tree with height h:

- Level 0: 1 node, weight = h
- Level 1: 2 nodes, weight = h-1 each
- Level i: 2^i nodes, weight = h-i each

Sum = Σ(2^i × (h-i)) for i=0 to h. This is a linear function of N nodes, so O(N).

**Question 12: Finding k smallest integers**

a)
i) **Selection Sort (k iterations): O(kN)**
Each iteration finds minimum in remaining elements.

ii) **Mergesort then return first k: O(N log N)**
Sorting dominates, returning first k is O(k).

iii) **Build min heap, delete k times: O(N + k log N)**
Build heap: O(N), k deletions: O(k log N)

b) **O(k + N log k) algorithm:**

```
1. Build a MAX heap of size k from first k elements: O(k)
2. For each remaining element (N-k elements):
   - If element < heap root, replace root and heapify: O(log k)
   - Total for this step: O((N-k) log k) = O(N log k)
3. Extract all k elements from heap: O(k log k)
Total: O(k + N log k + k log k) = O(N log k + k)
```

The heap maintains the k smallest elements seen so far.

**Question 13: Graph Data Structure**

**Data Structure:**

1. **Adjacency List**: Array of doubly linked lists

   - Index i contains doubly linked list of vertices adjacent to i
   - Each node in list stores vertex j and has prev/next pointers

2. **Hash Table**:
   - Key: (i, j) pair
   - Value: pointer to the node in adjacency list representing edge (i, j)

**Operations:**

- **insert(i, j)**: O(1)

  - Create new node for j in adjacency list of i
  - Insert into hash table with key (i, j)

- **delete(i, j)**: O(1)

  - Look up (i, j) in hash table to get node pointer
  - Use doubly linked list pointers to remove node in O(1)
  - Delete from hash table

- **exist(i, j)**: O(1)

  - Look up (i, j) in hash table

- **neighbours(i)**: O(n_i)
  - Traverse adjacency list of i

The doubly linked list allows O(1) deletion when we have a pointer to the node, and the hash table provides O(1) lookup of that pointer.
