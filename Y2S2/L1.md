# Strings

Null-character (‘\0’) terminated character arrays

- Null-character tells us where the string ends
- All standard C library functions on strings assume null-termination.

# Signed integers

- Two’s complement, MSB = sign

Default in C: int is signed unless specified unsigned.

Note:

- Default in C: int is signed unless specified unsigned.
- Good for most arithmetic unless you know the value is always ≥ 0.

# Unsigned integers

Unsigned:

- Only represent 0 and positive numbers.
- Every bit contributes to the value (no sign bit).
- (8-bit unsigned) Max value = 2ⁿ - 1 (for n bits)

Use when:

- The value is never negative
- You want larger positive range with the same number of bits

# Memory management

Note:

- Malloc what you free, free what you malloc.
- mallocs > frees → memory leak
- mallocs < frees → double free (can cause crashes , free a malloced block exactly once.)

## malloc

- Allocates a memory block of `size` bytes.
- Memory is **not initialized** (malloc just grabs a block of memory from the system, contents are garbage — whatever was already in that memory before.)

```c
int *arr = (int*) malloc(5 * sizeof(int)); // array of 5 ints
if (arr == NULL) {
    // handle allocation failure
}
```

## calloc

- Allocates memory for an array of num elements, each size bytes.
- Memory is initialized to zero. (allocates memory and sets every byte to 0.)

```c
int *arr = (int*) calloc(5, sizeof(int)); // array of 5 ints, all 0
if (arr == NULL) {
    // handle allocation failure
}
```

## free

- Frees memory previously allocated by malloc, calloc, or realloc.
- Use exactly once per allocation.

```c
free(arr);
arr = NULL; // good practice to avoid dangling pointer
```

## sizeof

```c
sizeof(int)   // size of int
sizeof(int*)  // size of pointer to int
```

# Stack vs Heap

## Stack

- Stores **local variables** and **function arguments**.
- Memory is **automatically deallocated** when the variable leaves scope.
- **Do NOT return a pointer** to a stack variable — it will become invalid.
- **Do NOT reference** a variable outside its scope.

```c
int* wrong() {
    int x = 5;      // x is on the stack
    return &x;      // ❌ BAD! Pointer will be invalid
}
```

## Heap

- Memory allocated by malloc, calloc, or realloc is on the heap.
- Memory persists until freed.

Safe to return pointers to heap memory from functions.

```c
int* right() {
    int *a = (int*) malloc(sizeof(int)); // heap memory
    *a = 10;
    return a; // ✅ Safe
}
```

# typedef

- `typedef` creates an **alias** (new name) for an existing type.

```c
typedef unsigned int uint;  // uint is now an alias for unsigned int
uint x = 100;
```

# Macros

Definition: Text substitution done by the preprocessor (`#define`).

- **No type checking or function call overhead.**

```c
#define INT_MAX 0x7FFFFFFFF
#define WORD_SIZE 4
#define MAX(A, B) ((A) > (B) ? (A) : (B))
#define REQUIRES(COND) assert(COND)
#define ENSURES(COND) assert(COND)
#define NEXT_WORD(a) ((char*)(a) + WORD_SIZE)
```

# Generic Types in C

- C does not have templates or generics like C++ or Java.
- Instead, it uses void\* as a generic pointer type.
- A void\* pointer can point to any type of memory, but the compiler doesn’t know the type.

Rules:

- Cannot dereference void\* directly

```c
void* p;
// *p = 5; // ❌ ERROR, cannot dereference void*
```

- Must cast to a proper pointer type first

```c
void* p = malloc(sizeof(int));
*(int*)p = 5;  // ✅ cast to int* before dereferencing
```

# Header files and Header Guards

Header files (.h) contain:

- Function prototypes (declarations)
- Struct definitions
- Macros

They do not contain implementation code (the actual function bodies).

Purpose: share common definitions across multiple .c files.

```c
#include <string.h>  // system headers
#include "list.h"    // user headers
```

```c
//Header guards

// grandfather.h
#ifndef GRANDFATHER_H
#define GRANDFATHER_H
// content
#endif

// father.h
#ifndef FATHER_H
#define FATHER_H
#include "grandfather.h"
#endif

// child.h
#include "father.h"
#include "grandfather.h"  // safe: grandfather.h included only once


// #ifndef = if not defined

// #define = define a macro

// #endif = end of guard
```

# Prefix and postfix increment/decrement

```c
Prefix vs Postfix increment/decrement
a++: use a in the expression, then increment a
++a: increment a, then use a in the expression

int a = 5;
printf("%d", a++); // prints 5, then a becomes 6
printf("%d", ++a); // increments first, prints 7
```

# Important C libraries

- string.h  
  Provides functions for string handling and memory operations.  
  Examples: strlen, strcpy, strcat, strcmp, memset, memcpy.

- stdlib.h  
  Provides functions for general utilities, memory management, and conversions.  
  Examples: malloc, calloc, free, atoi, rand, exit.

- stdio.h  
  Provides functions for input and output (I/O).  
  Examples: printf, scanf, fgets, fputs, fopen, fclose.

# Makefile

Saves you from typing long commands with flags every time to run C program.

```bash
# Instead of
gcc -Wall -g -o myprogram main.o helper.o

# Just run
make
```

```bash
# Short example Makefile

CC = gcc
CFLAGS = -Wall -g

myprogram: main.o helper.o
    $(CC) $(CFLAGS) -o myprogram main.o helper.o

main.o: main.c helper.h
    $(CC) $(CFLAGS) -c main.c

helper.o: helper.c helper.h
    $(CC) $(CFLAGS) -c helper.c

clean:
    rm -f *.o myprogram
```
