# Strings

Null-character (‘\0’) terminated character arrays

- Null-character tells us where the string ends
- All standard C library functions on strings assume null-termination.

# Signed integers

- Two’s complement, MSB = sign

Default in C: int is signed unless specified unsigned.

Note:

- Default in C: int is signed unless specified unsigned.
- Good for most arithmetic unless you know the value is always ≥ 0.

# Unsigned integers

Unsigned:

- Only represent 0 and positive numbers.
- Every bit contributes to the value (no sign bit).
- (8-bit unsigned) Max value = 2ⁿ - 1 (for n bits)

Use when:

- The value is never negative
- You want larger positive range with the same number of bits

# Memory management

Note:

- Malloc what you free, free what you malloc.
- mallocs > frees → memory leak
- mallocs < frees → double free (can cause crashes , free a malloced block exactly once.)

## malloc

- Allocates a memory block of `size` bytes.
- Memory is **not initialized** (malloc just grabs a block of memory from the system, contents are garbage — whatever was already in that memory before.)

```c
int *arr = (int*) malloc(5 * sizeof(int)); // array of 5 ints
if (arr == NULL) {
    // handle allocation failure
}
```

## calloc

- Allocates memory for an array of num elements, each size bytes.
- Memory is initialized to zero. (allocates memory and sets every byte to 0.)

```c
int *arr = (int*) calloc(5, sizeof(int)); // array of 5 ints, all 0
if (arr == NULL) {
    // handle allocation failure
}
```

## free

- Frees memory previously allocated by malloc, calloc, or realloc.
- Use exactly once per allocation.

```c
free(arr);
arr = NULL; // good practice to avoid dangling pointer
```

## sizeof

```c
sizeof(int)   // size of int
sizeof(int*)  // size of pointer to int
```
